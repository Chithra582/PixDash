# Platformer Mechanics Architect Skill

## Overview
Engineers tight, responsive 2D character controllers in Unity C# using Rigidbody2D kinematics, asymmetric gravity scales, and input buffering.

## Operations
1. Formulates variable jump height with distinct rise and fall gravity multipliers.
2. Implements coyote time timers ($150\text{ms}$) for forgiving ledge jumps.
3. Implements jump input buffering ($100\text{ms}$) to catch early button presses.
4. Serializes all physics parameters for seamless Unity Inspector tuning.
